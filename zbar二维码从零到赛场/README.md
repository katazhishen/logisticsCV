## 一、先回答三个问题

**1. 为什么算法组要学读二维码？**

翻开《智能赛道命题.pdf》，智能搬运赛项的功能要求里有一句：

> 能读取二维码、条码、图形、数字、文字、颜色等信息 —— 完全自主

任务码（比如 `156+123+516+231`）就是这一局比赛的**全部指令**：
搬哪三个颜色、按什么顺序、放到几号圆环、第二批怎么码垛，全在这 15 个字符里。

读不出来 = 不知道干什么 = 0 分。这是整场比赛的**第一个门槛**，也是最早能跑通、
最能给你正反馈的一环。所以算法组从它开始练手，是最划算的。

**2. zbar 是什么？**

`zbar` 是一个专门"找码 + 认码"的 C 语言库，2006 年就有了，Linux/树莓派/树莓派
摄像头生态里到处是它。`pyzbar` 是它的 Python 包装，让你三行代码就能读码。

它和 `OpenCV` 的 `QRCodeDetector` 是**两套独立实现**：一套用 ZBar 自己的扫描线算法，
一套用 OpenCV 的图形检测。它们各有盲区 —— 这一点第 09 课会用数据说清楚，
第 10 课会把两者拼成一个更结实的读码器。

**3. 这份教程和网上那些"3 行代码读二维码"有什么区别？**

网上那 3 行代码只能在**干净图片**上工作。而赛场上的真实画面是：
A4 板歪着贴在场地边缘、80mm 的码在画面里只有几十像素、头顶灯管一片反光、
车还在抖。这份教程花 10 课时间，把"读不出"的每一种原因都拆开、量化、给解药。

**现在就想跑？** 三条命令，三十秒见效（在教程根目录下执行）：

```bash
conda activate OpenCV_Linux                     # 用你已有的 OpenCV 环境（见第三节）
cd "/home/kata/Desktop/logisticsCV/zbar二维码从零到赛场"
python code/env_check.py                        # 环境体检，8 项应全 OK
python code/lesson03_read_one.py                # 批量读全部素材图，最后给出结论
python code/lesson10_reader.py --self-test      # 11 级流水线自动挑药
```

这三条能过，说明环境和代码都是好的，可以直接从第 03 课往下学。

## 三、环境（这份教程实测过的版本）

**用你机器上已有的 conda 环境 `OpenCV_Linux`，不要新建环境。**

```bash
conda activate OpenCV_Linux
python code/env_check.py          # 8 项全 OK 就可以开始了
```

| 组件 | 版本 | 作用 |
|------|------|------|
| Ubuntu | 22.04.5 | 操作系统 |
| conda 环境 | `OpenCV_Linux`（`/home/kata/yes/envs/OpenCV_Linux`） | 本教程运行环境 |
| Python | 3.11.16 | 语言 |
| opencv-python | 5.0.0 | 图像处理、摄像头 |
| numpy | 2.4.6 | 数组运算 |
| Pillow | 12.3.0 | 图片读写 |
| qrcode | 8.x（本教程 `pip install` 补装） | **造**二维码 |
| pyzbar | 0.1.9（本教程 `pip install` 补装） | zbar 的 Python 包装 |
| libzbar | 0.23.92-4build2 | zbar 本体（**系统已装**；另自带 `vendor/` 一份兜底） |

> **`OpenCV_Linux` 里原本缺 `qrcode` 和 `pyzbar`**，这两个都是纯 Python 包，一条命令补齐：
> ```bash
> pip install qrcode pyzbar
> ```
> 不想每次 `conda activate`，就用绝对路径：
> `/home/kata/yes/envs/OpenCV_Linux/bin/python code/env_check.py`

> **（诚实交代）**教程最初在系统 Python 3.10 上写，为了不污染系统，我在教程目录建过一个 `.venv`。
> 后来发现有现成的 `OpenCV_Linux`，那个 `.venv` 已经删掉了 ——
> **一个项目一个环境就够了，多出来的环境是负担，不是保险。**

**关于 zbar 本体：两条路，`bootstrap` 自动选。**

- **正路**：`sudo apt install -y libzbar0` —— 本机**已经这样装好了**
  （`/lib/x86_64-linux-gnu/libzbar.so.0`，0.23.92-4build2），所以 `env_check.py`
  报的是 `使用系统安装的 libzbar`。
- **兜底路**：本教程自带 `vendor/lib/libzbar.so.0`，由 `code/zbar_bootstrap.py`
  手动加载 + 猴补丁 `find_library`，**不需要 root**。适用于赛场机、树莓派、借来的电脑。

`zbar_bootstrap.py` 第一句就是"先试正路"（`if find_library("zbar"): return "system"`），
所以你装了系统库之后一行代码都不用改。原理与完整踩坑记录见`第 02 课` §5。

> 可选：`sudo apt install -y zbar-tools` 会额外装上命令行工具 `zbarimg`
> （本机目前只装了库，没装工具；`vendor/zbarimg` 照样能用）。

## 五、怎么用每一课

每一课都是同一个结构，别跳着看：

```
1. 本课要解决的问题     ← 先知道"为什么学这个"
2. 打比方讲原理         ← 建立直觉，不要背
3. 动手（命令 + 代码）   ← 一定要自己跑
4. 参考答案 / 参考结果   ← 折叠在每道题下面，先自己写，写完再点开对
5. 批注                 ← 那些"书上不写但会坑你"的细节
6. 常见错误             ← 报错信息 → 原因 → 解法
7. 自测题               ← 每题自带折叠答案；答不上来就回去重看，别糊过去
8. 下一课衔接           ← 一环接一环的原因
```

> **答案都是折叠的**：练习和自测题下面的那条折叠条，点开才是答案。
> 先自己写、先自己答，对不上再点开 —— 直接扫答案会把"我懂了"变成"我看过"。

**所有命令都在教程根目录下执行**（就是这个 `zbar二维码从零到赛场/` 文件夹）：

## 七、一句提醒

这份教程里所有"结论"都是用实跑数据得出的，包括几个**反直觉**的：

- 安静区（白边）单独放白底时 `border=0` 也能读（第 04 课实测）
- 放大码**不一定**要用最近邻插值，要看原图是怎么缩小的（第 09 课实测）
- zbar 的耗时和"内容"强相关，不是固定值（第 09 课实测）
- 流水线注释写着"按成本从低到高排序"，实际把最贵的三级排在了第三位（第 10 课自查抓出来的）
- `straight` 摆正的硬要求是"每格 ≥2 像素 + 最近邻"，补白边只是保险（第 12 课实测）

**别背我的数字，学会我的方法。** 你的摄像头、你的场地光照、你的打印纸，
数据一定和这里不一样。每课都留了"换你自己的图再跑一遍"的口子，那才是真正学到的东西。
